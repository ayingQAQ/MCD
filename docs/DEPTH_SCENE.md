# 星系纵深改造

目标是前后空间关系，而不是给固定分组增加表面装饰。保留 Canvas2D、真实营养和图算法。

- 星球不再按类别聚团。所有 ID 在超过 4000 单位宽的空间独立分散，位置与深度均不由营养或类别决定；远景更淡、更小，前景遮挡后景。
- 首页镜头保持 78%（手机）或 90%（桌面）的探索倍率，只显示附近的局部星空；拖动后进入其他区域，重置返回出发位置，不再自动缩小至全图。深色墨蓝星空搭配暖金星尘，保留手绘食物与纸质控制面板。
- 镜头平移使不同深度移动不同距离，星空/雾层与星球形成连续视差；滚轮以所指深度平面为锚点。
- 绘制、命中、标签、连线和聚焦共享同一套投影。关系按投影后的曲线检测，不能只改视觉却仍点击旧坐标。
- 营养基础半径仍由原值计算；透视会改变屏幕大小，页面说明大小含透视缩放，不将深度解释为营养指标。
- 固定种子、无运行时 AI 或 3D 引擎；减少动态效果时关闭漂移，保留交互产生的空间投影。

新增几何测试先由 Actions 确认失败，再实施；既有搜索、路线、原生触控和四视口检查继续保留。全部测试与构建使用 GitHub Actions。
