# 商品图片来源与覆盖

营养数据和商品图片是两份独立数据。营养数值仍只来自 `list-nutrition-foods`；该接口不提供图片。

## 图片获取

- 来源：`query-meals` 的菜单图片；优先采用 `query-meal-detail` 确认后的商品名称、规格与图片。
- 采样：上海黄浦华旭国际大厦餐厅（1450713），公开菜单样本；非用户位置、非库存，也不采集账户地址或订单。
- 时间：2026-10-21T13:19:17.785Z
- 早餐菜单：预约日期 2026-10-22 08:30，仅查询，没有创建订单。
- 原始 CDN：`https://menu-img.mcd.cn/`。每个已匹配条目保留来源 URL、商品编码、接口、菜单名及映射方式，见 `src/data/food-images.json`。
- 图片为接口返回的商品展示图，非项目原创插画；第三方品牌及图片权益属于原权利人，仅用于本项目餐品信息展示。
- 仅缓存已审核的 URL。运行 `node scripts/cache-food-photos.mjs` 更新本地缓存；不会从营养值推断商品、杯型、配方或远程文件地址。

## 显示规则

68 / 158 款已确认映射。精确名称与人工核实的别名均保留原名；冰/热、大/中/小、4块/5块不合并。未匹配或图片读取失败时显示中性占位「暂无已核实商品图片」。不会把组合套餐图绑定成单品。

商品图片用于图鉴与详情，原创卡通 SVG 用于三维世界中的食物星球。卡通只表达通用形态，不代表官方商品配方。SVG 在构建前生成，纹理按母版复用，使用真实世界坐标、透视、深度测试和 GPU 资源释放。
