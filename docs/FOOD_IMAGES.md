# 商品图片来源与覆盖

营养数据和商品图片是两份独立数据。营养数值仍只来自 `list-nutrition-foods`；该接口不提供图片。

## 图片获取

- 来源：`query-meals` 的菜单图片；优先采用 `query-meal-detail` 确认后的商品名称、规格与图片。
- 采样：上海黄浦华旭国际大厦餐厅（1450713），公开菜单样本；非用户位置、非库存，也不采集账户地址或订单。
- 初次采样：2026-10-21T13:19:17.785Z；本次扩充：2026-10-21T17:10:01.039Z
- 采样时段：原菜单；2026-10-22 08:30 早餐、15:00 下午茶。另只读抽查上海福州路、静安寺、越洋广场公共菜单，未将其他门店素材混入清单。所有操作仅查询，没有创建订单。
- 官网补充：冰焦糖玛奇朵与热焦糖玛奇朵分别取自同中文名称的 [冰款商品页](https://www.mcdonalds.com.cn/product/Iced-Caramel-Macchiato-2)、[热款商品页](https://www.mcdonalds.com.cn/product/Hot-Caramel-Macchiato-2) 主商品图。HTML 中直接读取图片地址，没有推测文件名；官网图片主机为 `officiaweb-afd.mcdonalds.com.cn`。这两项 `sourceTool` 为 `official-product-page`，保留逐项 `sourcePage`，不属于门店菜单采样；两项 `code` 为带 `official-` 前缀的本地资源标识，不是 MCP 餐品编码。
- 原始 CDN：`https://menu-img.mcd.cn/`。每个已匹配条目保留来源 URL、商品编码、接口、菜单名及映射方式，见 `src/data/food-images.json`。
- 图片为接口返回的商品展示图，非项目原创插画；第三方品牌及图片权益属于原权利人，仅用于本项目餐品信息展示。
- 仅缓存已审核的 URL。运行 `node scripts/cache-food-photos.mjs` 更新本地缓存；不会从营养值推断商品、杯型、配方或远程文件地址。

## 显示规则

86 / 158 款具有准确规格或已审核别名的商品图；另 26 款显示明确标注的同款不同尺寸参考，共 112 / 158 款可显示图片。参考图保留实际菜单名、编码与原图 URL，并显示「同款中杯参考图 · 当前为大杯」等说明；不宣称是当前规格的准确外观。冰/热、风味、牛奶/燕麦奶不交叉替用。未匹配或读取失败时显示中性占位；不会把组合套餐图绑定成单品。

商品图片用于图鉴与详情，原创卡通 SVG 附在三维世界中受光照的食物球体表面。卡通只表达通用形态，不代表官方商品配方。SVG 在构建前生成，纹理按母版复用，使用球面曲面网格、真实世界坐标、光照、透视、深度测试和 GPU 资源释放。
