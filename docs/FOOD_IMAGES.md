# 商品图片来源与覆盖

营养数据与图片分别保存。营养记录仍来自 `list-nutrition-foods`，该接口不含图片；`query-meals` 与 `query-meal-detail` 返回特定门店、时段的菜单商品图片。

## 当前覆盖

138 / 158 条原始餐品规格可显示图片：101 条准确规格或经核对的别名，37 条带公开标注的同款尺寸参考。图片只按已经确认的名称和规格绑定，不通过营养值推断食物。

| 图片来源 | 规格数 | 取图方式 |
| --- | ---: | --- |
| MCP 门店菜单/详情 | 112 | 接口返回的原始图片 URL；本地静态缓存 |
| 官网营养计算器 | 17 | 页面内 Product 数据的同中文名称与 media_url |
| 官网商品页 | 5 | 同名商品页主商品图 |
| 官网套餐推广页 | 4 | 同名组合的原始推广图，包含真实餐品照片；不绑定为其中的单品 |

图鉴将同款饮品的杯型合并，158 条规格显示为 117 张卡片，其中饮品 40 张。默认中杯，没有中杯时使用最小的已收录杯型；名称前置与后置的杯型都支持。详情杯型选择使用原始餐品 ID，营养、收藏、实验台与分享仍对应具体规格；搜索含杯型时仍可定位相应规格。冰/热、口味、牛奶/燕麦奶不合并。星系原始餐品对象与营养算法保持原样。

## 来源边界

- MCP 主要采样门店：上海黄浦华旭国际大厦餐厅（1450713），含早餐与下午茶；另只读查看上海、北京、广州若干公共门店。非用户位置、非库存，不采集地址或订单，不创建订单。
- 官网营养计算器：[nutrition_calculator](https://www.mcdonalds.com.cn/nutrition_calculator)。只读取明确提供的图像地址，不同步其营养值覆盖 MCP 快照。
- 官网商品页分别确认冰/热焦糖玛奇朵、草莓/柠檬拉明顿与酥酥多笋卷。套餐推广图来自 [500 kcal 系列](https://www.mcdonalds.com.cn/news/20250516-500kcal)，是历史推广材料，图中文字及价格不代表当前供应或价格。
- 每条记录保留 `sourceTool`、`sourcePage`（官网）、菜单名、原始 URL、映射方式与本地路径，见 [映射清单](../src/data/food-images.json)。带 `official-` 前缀的 code 是本地资源标识，不是 MCP 商品编码。
- MCP 图片原始主机为 `menu-img.mcd.cn`；官网为 `officiaweb-afd.mcdonalds.com.cn`。图片权益属于原权利人，仅用于餐品信息展示。
- `node scripts/cache-food-photos.mjs` 只缓存审核过的 URL，检查白名单主机、来源页及图像文件头；无需 Token。运行时只请求本地静态图片，不调用认证 MCP。
- 商品实拍用于图鉴和档案，原创 SVG 用于三维食物星球，两者不互相冒充。读取失败或没有已确认来源时使用明确占位。
