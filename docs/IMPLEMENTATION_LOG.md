## 已知边界

- 数据是手动同步的营养快照，不表示门店实时在售；分类为名称规则推断。
- 部分单位和计量基准未确认，界面/导出均显式注明；图谱比较的是接口所列规格原始数值轮廓。
- 全量158节点在小屏默认缩放较小，适合通过搜索、图鉴或缩放探索；全部名称同时打开时仍可能发生标签重叠。
- 数据同步与Cloudflare发布为显式操作；普通push自动验证和产出静态包，不自动使用个人MCP Token或重新发布站点。
