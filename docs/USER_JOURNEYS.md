# McCosmos 2.0 使用路径与验收

## 60 秒探索脚本

1. 打开观测站，点“开始探索”；阅读或跳过引导，在星系搜索“巨无霸”，查看 513 kcal 与原始指标。
2. 收藏星球、加入实验室；切到图鉴，搜索另一款餐品，查看来源与相似邻居，再加入实验室。
3. 在实验室查看五个独立量尺与第二项减第一项差值；交换样本，保存星球对照卡。
4. 点“在星系中查看关系”，确认带入的起点和终点，点出发；上一站/下一站/播放/退出均有实际状态。
5. 打开探索任务，从线索选择真实候选，验证后领取星章；刷新确认进度，分享成果 PNG。首页最近查看与收藏数同步。

## 数据与功能边界

- 官方快照 160 条原始记录去重后 158 条，非实时在售数据。页面统一显示来源、时间、结构/算法版本。
- 当前部分单位与计量基准未核实，原始值差异不代表每份或等重量差异；相近度不是健康评分。
- 31 个通用食物 SVG 示例不代表认证配方；无法确认形态使用纸袋，支持手动配置新母版。
- 收藏与每日任务没有账号同步。新日期/新数据版本生成新任务；数据不足时任务不可用。
- 服务器不保存个人凭据或收藏；未接入订单、领券、会员资料或运行时模型。

最终通过数量、Actions 链接、截图审阅及部署版本记录在 `IMPLEMENTATION_LOG.md`。
