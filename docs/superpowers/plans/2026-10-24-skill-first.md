# McCosmos Skill 核心能力优化

依据：2026-10-24 的规则核对及用户“帮我优化执行”。用户已选择直接实施；保留 main、现有网页与数据算法，验证和打包在 GitHub Actions 执行。

## 目标与取舍

将 McCosmos 定位为餐品营养对比与替代发现 Skill，网页作为可视化入口。复用现有 TypeScript 分析和比较函数；不另建推荐模型、不把营养相似度称作健康评分。相比只改 README，此方案补齐可执行能力；相比重构整个网站，改动范围小且能复用现有成果。

## 实施任务

1. **任务测试先行**：新增 CLI 工作流测试，涵盖两餐品比较、带热量上限的检索、相似替代、原值单位、缺失/零值、重名、无候选及参数错误。GitHub Actions 先记录现有命令不支持的失败，再实现。
2. **共享 CLI**：保留 list/neighbors/route/discover 契约，增加 search/compare/alternatives。比较输出原始规格、逐项差异及来源边界；替代在全快照归一化基准上计算，不重排原有图算法。输出网页定位链接，不声称链接已完成实验室或任务操作。
3. **可携带运行包**：复用 Vite 构建 Node CLI，随 Skill 打包营养快照、必要文档和许可。Node 24 即可从任意目录执行，无需克隆或安装依赖。支持外部快照及带明确获取时间的 MCP 原始响应，失败不悄悄回退。
4. **Skill 工作流**：更新 SKILL.md 与按需命令参考，明确自然语言触发、MCP/快照选择、规格消歧、输出证据与可视化入口。安装步骤放根 README；不自动修改用户客户端或 MCP 配置。
5. **验收及呈现**：Actions 在项目外临时目录执行独立包，保存请求/结构化输出/断言证据并上传 Skill 包。独立 Agent 对典型请求进行一次实际试用，区分它和完整客户端自动发现验收。重排 README、更新 About，准备参赛简介草稿。

## 验收

- 原 CLI 命令兼容；新增筛选无空值补零、无偷偷选重名、无放宽用户限制。
- 原始单位、计量基准、来源时间与同款杯型保持可追溯。
- 纯 Node 独立包在无项目依赖目录中可运行，错误响应非零退出。
- Actions 单测、类型、lint、构建、浏览器回归及独立 Skill 验收通过。
- 官方声明保持原样，Token 不进入任何包或客户端网页。
