依据：2026-10-24 的规则核对及用户“帮我优化执行”。用户已选择直接实施；保留 main、现有网页与数据算法，验证和打包在 GitHub Actions 执行。

## 目标与取舍

将 McCosmos 定位为餐品营养对比与替代发现 Skill，网页作为可视化入口。复用现有 TypeScript 分析和比较函数；不另建推荐模型、不把营养相似度称作健康评分。相比只改 README，此方案补齐可执行能力；相比重构整个网站，改动范围小且能复用现有成果。

## 实施任务

1. **任务测试先行**：新增 CLI 工作流测试，涵盖两餐品比较、带热量上限的检索、相似替代、原值单位、缺失/零值、重名、无候选及参数错误。GitHub Actions 先记录现有命令不支持的失败，再实现。

5. **验收及呈现**：Actions 在项目外临时目录执行独立包，保存请求/结构化输出/断言证据并上传 Skill 包。独立 Agent 对典型请求进行一次实际试用，区分它和完整客户端自动发现验收。重排 README、更新 About，准备参赛简介草稿。
